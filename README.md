# Start 教学管理系统（学习项目）

跟着黑马程序员视频做的练习项目，练习 JavaWeb 全链路开发。
目前完成度约 60%。

## 技术栈
Java / Spring Boot / MyBatis / MySQL / Maven

## 进度
- [√] 环境搭建、Maven 配置
- [√] 部门管理（增删改查）
- [√] 员工管理（增删改查）
- [ ] 登录认证（JWT）
- [ ] 文件上传
- [ ] 项目部署

## 怎么跑
1. 用 IDEA 打开项目
2. 建一个 MySQL 数据库，导入 sql 脚本
3. 修改 application.yml 里的数据库账号密码
4. 运行启动类

## 说明

本项目基于黑马程序员《AI+JavaWeb开发入门》课程案例练习，用来熟悉
Spring Boot + MyBatis + MySQL 的开发流程。

课程内容之外，我会持续在这里加自己的改动：
- 列表查询改成分页 + 多条件搜索
- 增加参数校验和统一异常返回
- 接入大模型，做一个能查数据、能回答问题的小助手
